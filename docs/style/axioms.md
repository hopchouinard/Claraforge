# Axioms & Punchlines

Short teaching lines for explaining Claraforge principles. Exact quotations below retain the source wording; audience adaptations are new editorial suggestions, not quotations or new principles. Source text was checked against commit `889205c108ea5689947c5c55edca5ba73f0d519c` on 2026-11-08.

## Canonical lines

| Exact phrasing | Origin principle | Intended use |
| --- | --- | --- |
| “Complexity doesn't vanish. It moves.” | [The Law of Cognitive Allocation](../../principles/PHIL-Law-of-Cognitive-Allocation.md#axioms) | Explain where complexity goes when a task is delegated. |

## Audience adaptations (editorial, not source quotations)

| Source line | Audience | Suggested adaptation |
| --- | --- | --- |
| Complexity doesn't vanish. It moves. | Technical teams | Automation relocates complexity; name who owns it next. |
| Complexity doesn't vanish. It moves. | General audience | A tool moves the hard part; it does not make every hard part disappear. |
| Placed fuel is power. | Team leads | Put effort where the team can turn it into results. |
| Placed fuel is power. | General audience | Effort helps most when it goes to the right place. |
| Memory is cheap for silicon… | Workshop participants | Let the machine hold the details while you exercise judgment. |
| Context is the mother lode of quality. | Technical teams | Share the constraints and examples before asking for a solution. |
| If you want brilliance… | New collaborators | A clearer question gives your collaborator a better starting point. |

## Using and maintaining this inventory

- Use a canonical line when quoting a principle. Link its source so readers can recover the nuance.
- Use an adaptation when the audience needs plainer or more concrete wording; identify it as an adaptation.
- Keep new entries short, attributed, and tied to an intended use. Do not present a proposed slogan as an established quotation.
