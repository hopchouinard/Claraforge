# Meta: Why It Works - AI Agent Template

## Instructions for AI Agents

Use this template to create "Meta: Why It Works" sections for ClaraForge principles. Each principle is part of an interconnected lattice that reinforces, complements, or balances other principles.

## Template Fields

### 1. Anchor Point

**Field Description:** A single, clear statement that captures the core value proposition of this principle.
**Instructions:** Write 2-4 sentences that explains how this principle creates value or solves a problem.
**Format:** Complete sentences ending with a period.

**Example:** "Allocation ensures complexity is carried by the right system. By matching tasks to the agent best equipped to handle them, we reduce friction and error. This principle clarifies responsibility, making it easier to debug and improve workflows. Ultimately, allocation frees up human creativity by letting machines handle routine complexity."

### 2. Synergy Links

**Field Description:** 2-4 connections to other principles showing how they work together.
**Instructions:**

- List 2-4 related principles by name
- For each connection, explain the relationship in one clear sentence
- Use the format: *Principle Name →* Explanation of how they connect
- Include both supportive relationships and balancing/contrasting ones

**Example:**

- *Quality In, Quality Out →* Inputs/outputs are matched to the system best able to handle them.
- *Raise the Floor, Not Just the Ceiling →* Baseline efficiency rises when humans stop wasting effort where machines excel.
- *Myth of the Divide →* Allocation reframes logic/creativity not as opposites but as tasks to be distributed.

### 3. Avoided Pitfall

**Field Description:** A clear explanation of what goes wrong when this principle is ignored or misapplied.
**Instructions:** Write 2-4 sentences describing the negative consequences or problems that arise without this principle.
**Format:** Complete sentence(s) showing the "what happens if we don't do this" scenario.

**Example:** "Without allocation, humans rubber-stamp AI 'judgment' and machines are strained into brittle roles."

## Complete Template Structure

```markdown
## Meta: Why It Works

**[ANCHOR POINT]** - [Write 2-4 sentences explaining how this principle creates value]

**Synergy Links:**
- *[Principle Name] →* [Explain how this principle supports or extends the named principle]
- *[Principle Name] →* [Explain the contrast or balance with the named principle]
- *[Principle Name] →* [Explain another connection - supportive or contrasting]

**Avoided Pitfall:** [Describe what happens when this principle is ignored or misapplied]
```

## Usage Notes

- Each field should be filled with specific, actionable content
- Focus on practical connections between principles
- Avoid generic statements - be specific about how principles interact
- The synergy links should show both how principles support each other AND how they balance/contrast
- The avoided pitfall should be concrete and relatable to real-world scenarios
